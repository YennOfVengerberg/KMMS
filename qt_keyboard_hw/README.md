# Разработка на Qt

## Установка

Согласно вашей ОС надо установить:

🪟 **Для Windows**

MSYS2 is a collection of tools and libraries providing you with an easy-to-use environment for building, installing and running native Windows software.

`https://www.msys2.org/`

Потом в терминале MSYS запустить команды для установки необходимого ПО и фреймворка Qt:
```
# Запускайте команды по очереди, т.к. объём скачиваемых файлов большой.
# Внимательно разберитесь как должны называться устанавливаемые gcc, cmake, ninja, qt6 согласно вашей ОС и архитектуре
pacman -S mingw-w64-ucrt-x86_64-gcc
pacman -S mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja
pacman -S mingw-w64-ucrt-x86_64-qt6
```

**И не забыть внести изменения в переменную окружения PATH, чтобы она и gcc, и cmake, и ninja (и qt) брала из msys**

🐧 **Linux**

Всё делалется через стандартный менеджер пакетов. Поскольку у вас gcc, cmake и ninja уже установлены, то надо установить только qt6, узнав как именно должно называться имя.

## Qt KeyBoard

Скопировать проект `2026_09_08_qt_keyboard` себе в репозиторий всех задач КММС и реализовать улучшения:  

1. Программа должна состоять из двух окон: окна приветствия с кнопкой `Перейти к клавиатуре` и окна клавиатуры.

2. Переход между окнами должен быть реализован через механизм `сигналов и слотов`.  

3. Сделать так, чтобы клавиши `букв, цифр, ввод, пробел, удалить` работали и через клавиатуру и через мышку. 

4. Поднять настроение Клавику!
